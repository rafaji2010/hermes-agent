The Hermes Worker Fleet

How the master brain plans work, the execution tooling that routes and measures it, and the fleet of harnesses that carries it out — with the result flow that runs back up.

The headline

Decide with evidence, dispatch by fit

HERMES plans; the runner routes each task to the best worker using measured performance, not assumptions. A slow or broken harness triggers retry and switch-on-failure instead of stalling the fleet.

Five harnesses, one interface

  • Pi — autonomous reasoning
  • Codex — repo-scale implementation
  • OpenCode — testing + implementation
  • CommandCode — review
  • DeepSeek Harness (dsh) — long-horizon, experimental

Results close the loop

Worker outputs return up through the dashed path: HERMES synthesizes them into a single answer for the user — while the benchmark keeps the routing evidence fresh.
